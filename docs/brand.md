# Brand — Anvil

_Status: active_

Anvil is a workshop, not a dashboard. Agents are tools on a forge: steel plates, brass fittings, ember heat.

## Palette

| Token | Hex | Use |
|---|---|---|
| soot | `#12100D` | page background |
| iron | `#1C1914` | sidebar, elevated plates |
| slag | `#2A241C` | card / input fill |
| steel | `#D4C4A8` | primary text |
| ash | `#9A8B78` | secondary text |
| ember | `#E06A2B` | single accent — CTAs, browser-agent heat |
| brass | `#C9A35A` | API-agent mark, rules, focus ring |
| bone | `#E8DFD0` | headings, high-emphasis text |

## Typography

- Display / wordmark: **Syne** (800) — industrial geometric
- Body / UI: **Figtree** — readable workshop labels
- Data / addresses / JSON: **IBM Plex Mono**

## Voice

Short, active, specific. Name things by what the user does (Run, Stake, Search), never by chain internals. Coming Soon is honest.

## Signature

Agent cards are stamped steel plates. A 3px left heat-mark: ember for browser agents, brass for API agents.
